Naver Blog Image Downloader for Chrome, version 0.2.1
SPDX-License-Identifier: GPL-3.0-only

This extension reimplements the DOM metadata selection and w3840 candidate
strategy from hsofficial/nblog-img-downloder by HyeonSu Na (hsofficial).
Reference revision: 0ebe1f83a9f6c8ae9cdbf72485f734c7472451bf
Reference URL: https://github.com/hsofficial/nblog-img-downloder
Access date: 2026-10-14

Changes: JavaScript port for Chrome Manifest V3, passive content scripts,
Korean popup interface, w3840-first URL candidates with other query fields
preserved, selection downloads, persisted queue, actual download completion
tracking, fallback, cancellation, atomic per-job folders, filename suggestions,
and a generated framed-N icon with a lower-left download badge.
Automatic downloading and selectable image quality were removed in 0.2.0.
Version 0.2.1 excludes typed non-photo links and sticker components from the
article scan, matching the 37-photo viewer in the reported Naver Blog post.
Explicit HTML/text/JSON/XML error artifacts created by this extension are
removed before retrying; ambiguous MIME types are retained for inspection.
The Selenium image-viewer/network selection is not included.

The gallery-dl Naver Blog extractor was consulted for strategy comparison:
https://github.com/mikf/gallery-dl/blob/master/gallery_dl/extractor/naverblog.py
No gallery-dl source files or dependencies are included in this extension.

Installation: open chrome://extensions, enable Developer mode, choose
Load unpacked, and select the unpacked directory containing manifest.json.
Reload existing Naver Blog tabs after installing.
Select images in the popup and press Download to start saving. Visiting a post
does not start downloads. Use Stop on a progress card to cancel existing work.
Reload the extension on chrome://extensions after updating. Legacy automatic
work is canceled during migration; manual work retains its saved folder.
